# 使用方式

Maven

```xml

<dependency>
    <groupId>io.github.kongweiguang</groupId>
    <artifactId>kong-spring</artifactId>
    <version>0.6</version>
</dependency>
```

Gradle

```
implementation 'io.github.kongweiguang:kong-spring:0.6'
```

Gradle-Kotlin

```
implementation("io.github.kongweiguang:kong-spring:0.6")
```
